# Vela

Open-source embedded Linux platform for **Qualcomm Snapdragon**, from [SoCcentric](https://github.com/Soccentric).
MIT licensed.

| Repository | Purpose |
|---|---|
| [Vela-OS](https://github.com/soccentric-vela/Vela-OS) | Yocto/kas image build |
| [meta-vela](https://github.com/soccentric-vela/meta-vela) | Yocto layer for the board |
| [Vela-HAL](https://github.com/soccentric-vela/Vela-HAL) | Hardware abstraction layer (C++17) |
| [Vela-Client](https://github.com/soccentric-vela/Vela-Client) | gRPC client (C++17) |
| [Vela-Server](https://github.com/soccentric-vela/Vela-Server) | Test server (Drogon, C++) |
| [Vela-Configuration](https://github.com/soccentric-vela/Vela-Configuration) | WebConfig on-device configuration |
| [Vela-Dashboard](https://github.com/soccentric-vela/Vela-Dashboard) | HTML5 dashboard |
| [Vela-PySDK](https://github.com/soccentric-vela/Vela-PySDK) | Python SDK |
| [Vela-Instrumentation](https://github.com/soccentric-vela/Vela-Instrumentation) | On-device management and observability |
| [Vela-HQ](https://github.com/soccentric-vela/Vela-HQ) | Fleet management |
| [Vela-Hardware](https://github.com/soccentric-vela/Vela-Hardware) | Hardware documentation |

Contributions go to the `develop` branch. See the shared [contributing guide](https://github.com/soccentric-vela/.github/blob/main/CONTRIBUTING.md).
